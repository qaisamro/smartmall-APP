# SmartMall App

تطبيق **SmartMall App** هو منظومة تسوق وإدارة متاجر للمراكز التجارية، تتضمن تطبيقاً محمولاً مبنياً باستخدام Expo وReact Native، بالإضافة إلى خدمات الواجهة البرمجية والواجهات المساندة الموجودة داخل هذا المستودع.

يوفر التطبيق تجربة تصفح المتاجر والمنتجات والعروض، إدارة السلة والطلبات، تتبع التوصيل، الإشعارات، الشكاوى، وواجهات تشغيل الموظفين ونقطة البيع حسب صلاحيات المستخدم.

## أهم المزايا

- واجهة عربية افتراضية مع دعم اللغة الإنجليزية.
- تفعيل اتجاه RTL تلقائياً عند استخدام اللغة العربية.
- تصفح المراكز التجارية والأقسام والمنتجات والعروض.
- سلة مشتريات وإنشاء طلبات مع خيارات الاستلام والتوصيل.
- متابعة حالة الطلب والتوصيل والإشعارات.
- تسجيل الدخول والتسجيل واستعادة كلمة المرور مع التحقق عبر WhatsApp.
- حساب شخصي وإعدادات المستخدم والشكاوى.
- واجهة POS للمالك والكاشير حسب الصلاحيات.

## المتطلبات الأساسية

قبل التشغيل، تأكد من توفر:

- [Node.js](https://nodejs.org/) إصدار 20 أو أحدث، ويفضل استخدام الإصدار المحدد في بيئة المشروع.
- [Git](https://git-scm.com/).
- مدير حزم: pnpm (الموصى به لهذا المستودع)، أو npm / Yarn عند تشغيل حزمة الهاتف بشكل مستقل.
- Expo CLI أو `npx expo` لتشغيل تطبيق React Native.
- Expo Go أو محاكي Android/iOS أو جهاز فعلي للتجربة الأصلية.

## تنزيل المشروع

```bash
git clone https://github.com/qaisamro/smartmall-APP.git
cd smartmall-APP
```

## التثبيت والتشغيل محلياً

### الطريقة الموصى بها باستخدام pnpm

من جذر المستودع:

```bash
corepack enable
pnpm install
```

أنشئ ملف إعدادات محلياً لتطبيق الهاتف:

```bash
cp artifacts/smartmall-mobile/.env.example artifacts/smartmall-mobile/.env
```

عدّل `EXPO_PUBLIC_API_BASE_URL` في الملف إذا كنت تستخدم خادماً محلياً أو بيئة اختبار. لا تضع كلمات مرور أو مفاتيح خاصة في متغيرات `EXPO_PUBLIC_*` لأنها تصل إلى تطبيق العميل.

شغّل تطبيق الهاتف:

```bash
pnpm --filter @workspace/smartmall-mobile run dev
```

### تشغيل Expo مباشرة

يمكن أيضاً تشغيل Expo من مجلد تطبيق الهاتف:

```bash
cd artifacts/smartmall-mobile
npx expo start
```

بعد تشغيل Expo:

- امسح رمز QR باستخدام Expo Go عند استخدام جهاز فعلي.
- اضغط `a` لتشغيل محاكي Android.
- اضغط `i` لتشغيل محاكي iOS على macOS.
- اضغط `w` لتشغيل نسخة الويب عند دعم البيئة لذلك.

### استخدام npm أو Yarn

إذا كنت تشغل حزمة الهاتف في بيئة npm أو Yarn بدلاً من pnpm:

```bash
cd artifacts/smartmall-mobile
npm install
# أو:
yarn install

npx expo start
```

في بيئة monorepo الكاملة، استخدم `pnpm install` من جذر المشروع لتثبيت كل حزم مساحة العمل بصورة صحيحة.

## تشغيل الخدمات الأخرى

لتشغيل خادم الواجهة البرمجية من جذر المشروع:

```bash
pnpm --filter @workspace/api-server run dev
```

ولتدقيق الأنواع في المشروع:

```bash
pnpm run typecheck
```

## اللغة والاتجاه

يضبط التطبيق اللغة العربية واتجاه RTL افتراضياً. يمكن للمستخدم تغيير اللغة من إعدادات الحساب إلى الإنجليزية، وعندها يتحول اتجاه الواجهة إلى LTR. يتم الحفاظ على النص العربي واتجاه RTL عند عرض الأرقام الغربية `0123456789`.

## هيكل المستودع

- `artifacts/smartmall-mobile/`: تطبيق Expo وReact Native المحمول.
- `artifacts/smartmall/`: واجهة الويب.
- `artifacts/api-server/`: خادم API المساند.
- `services/`: خدمات وتكاملات المشروع الأخرى.
- `lib/`: مكتبات مشتركة.

## ملفات البيئة والأمان

ملفات البيئة المحلية مثل `.env` غير مضافة إلى Git وممنوعة من الرفع إلى GitHub. استخدم ملفات `.env.example` كنقطة بداية، ولا ترفع مفاتيح API أو كلمات المرور أو رموز الجلسات أو الشهادات الخاصة.
