### ⚠️ تعديلات مطلوبة على الخطة

#### 1. بخصوص Firebase Project

**ليس لدينا Firebase project جاهز حالياً.**

المطلوب منك:
- إنشاء Firebase project جديد باسم `smartmall-fcm` (أو أي اسم مناسب)
- تزويدي بـ:
  - `google-services.json` → يوضع في `frontend/android/app/`
  - Service Account JSON → يوضع في `backend/storage/app/firebase.json` (هذا هو المفتاح السري، لا يوضع في Git)

**ملاحظة مهمة:** تأكد من عدم الخلط بين الملفين:
- `google-services.json` → خاص بتطبيق Android (يمكن وضعه في الـ repo)
- Service Account JSON (firebase.json) → المفتاح السري (يُضاف إلى `.gitignore`)

---

#### 2. بخصوص AuthController@logout

**لا نعدل AuthController@logout حالياً.**

بدلاً من ذلك:
- نعتمد على endpoint مستقل لحذف FCM token
- الـ Frontend يستدعي `DELETE /push/fcm-token` عند logout
- هذا يقلل التغيير في Authentication ويجنبنا مخاطر إضافية

---

#### 3. بخصوص Frontend Integration

**التعديلات المطلوبة في Frontend:**

```javascript
// frontend/src/services/fcmService.js
// أضف شرطاً إضافياً للتأكد من أن المستخدم مسجل دخوله قبل تسجيل FCM
// لأن push/fcm-token يحتاج auth:sanctum

export const initFcm = async () => {
  if (!Capacitor.isNativePlatform()) return;
  
  // تحقق من وجود token أولاً
  const token = localStorage.getItem('access_token');
  if (!token) return; // لا نسجل FCM إذا كان المستخدم غير مسجل دخوله
  
  // باقي الكود كما هو مقترح...
};
```

---

#### 4. بخصوص Backend - إرسال الإشعارات

**نحتاج توضيحاً بخصوص متى يتم إرسال FCM:**

في كل مكان يُستدعى فيه `PushNotificationService::sendToUser` حالياً، نضيف بجانبه:

```php
// مثال: OrderController.php
PushNotificationService::sendToUser($user, $title, $body, $url);
FcmNotificationService::sendToUser($user, $title, $body, $url); // الجديد
```

**السؤال:** هل تفضل:
- **الخيار A:** إرسال FCM بالتزامن مع Web Push (كلا القناتين)
- **الخيار B:** إرسال FCM فقط إذا كان المستخدم لديه توكن FCM مسجل، وإلا يرسل Web Push فقط

**أفضّل الخيار B** لتجنب إرسال إشعارات مكررة للمستخدمين الذين لديهم كلا القناتين.

---

#### 5. بخصوص الجدول - إضافة حقل

**أضف حقل `app_version` إلى جدول `fcm_tokens`:**

```php
Schema::create('fcm_tokens', function (Blueprint $table) {
    $table->id();
    $table->foreignId('user_id')->constrained()->cascadeOnDelete();
    $table->string('token', 512)->unique();
    $table->string('platform', 20)->default('android');
    $table->string('device_id')->nullable();
    $table->string('app_version')->nullable(); // جديد
    $table->timestamp('last_used_at')->nullable();
    $table->timestamps();
    $table->index(['user_id', 'platform']);
});
```

**السبب:** لتتبع إصدار التطبيق عند تسجيل التوكن، مفيد لاحقاً لإرسال تحديثات قسرية أو تنبيهات الإصدار.
