# SmartMall Mobile — Full Feature Gap Analysis

We need to perform a comprehensive **feature parity audit** between the existing production SmartMall system and the new standalone React Native / Expo mobile application.

This is an **AUDIT FIRST** task.

Do NOT start implementing missing features immediately.

The goal is to discover exactly:

1. What functionality currently exists in the production website.
2. What functionality exists in the Laravel backend/API.
3. What functionality exists in the old/current GitHub codebase.
4. What functionality already exists in the new React Native mobile app.
5. What functionality is missing from the mobile app.
6. Which missing functionality should actually be added to the mobile app.
7. Which functionality is intentionally web/admin-only and should NOT be added to the mobile app.

# STEP 13 — PRIORITIZATION

After finding all gaps, classify them:

## P0 — Must Have Before Release

## P3 — Future

Can safely wait for a later version.
