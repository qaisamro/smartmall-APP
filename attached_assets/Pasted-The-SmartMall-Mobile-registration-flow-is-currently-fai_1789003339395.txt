The SmartMall Mobile registration flow is currently failing with:

"Unable to connect to the server. Please check your internet connection."

This happens when creating a new customer account.

Investigate and fix ONLY the mobile registration/API integration issue.

## STRICT SCOPE

Inspect:

* `/artifacts/smartmall-mobile`
* the existing Laravel registration endpoint and its actual request contract

Do not redesign the app.

Do not modify unrelated features.

Do not start Phase 4.

Do not change the database unless absolutely required.

## INVESTIGATION

Trace registration end-to-end:

Mobile registration screen
→ centralized API client
→ POST `/api/v1/register`
→ Laravel route
→ controller
→ validation
→ response

Verify:

1. The mobile app is using the correct API base URL.
2. The actual request URL is exactly:
   `https://samrtmall.cloud/api/v1/register`
3. The HTTP method is POST.
4. Request headers are correct.
5. Content-Type is correct.
6. The JSON/body field names exactly match the Laravel endpoint.
7. The registration payload does not contain unsupported fields.
8. The Laravel endpoint is reachable from the Expo/native environment.
9. HTTPS/TLS is valid.
10. The API response format is correctly handled by the mobile client.
11. 422 validation responses are not incorrectly classified as network errors.
12. Axios/network error handling is not hiding the real server response.
13. The mobile registration request is not accidentally using a development/non-routable API URL.
14. No request is being sent to the website URL instead of `/api/v1/register`.

## IMPORTANT

Do not simply replace the error message.

Find the actual root cause.

If the server returns:

* 422 → show the real validation fields in a friendly way.
* 401/403 → handle authentication/authorization correctly.
* 404 → report endpoint mismatch.
* 429 → show rate-limit message.
* 5xx → show server error.
* network/TLS failure → distinguish it from an HTTP response.

Do not expose raw Laravel exceptions to customers.
