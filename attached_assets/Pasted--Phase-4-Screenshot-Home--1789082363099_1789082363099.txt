نبدأ Phase 4.

لا يوجد لدي تصميم أو Screenshot للصفحة الرئيسية، لذلك أريد منك تصميم Home احترافية من الصفر لتطبيق SmartMall Mobile، مع الحفاظ على هوية SmartMall الحالية.

مهم جدًا:

* لا تعدّل Backend.
* لا تعدّل Laravel.
* لا تعدّل Hostinger.
* لا تعدّل API endpoints.
* لا تعدّل قاعدة البيانات.
* لا تعدّل الموقع الحالي.
* لا تغيّر Capacitor.
* لا تضف dependencies جديدة إلا إذا كانت ضرورية جدًا.
* لا تغيّر أي شيء من Checkout أو Orders أو QR Scanner الذي تم اختباره ونجح.
* التعديل في هذه المهمة يكون على Home وتجربة التنقل فقط.

أريد Home Mobile حديثة، بسيطة وسريعة، وليست نسخة من موقع Desktop.

رتّب الصفحة بهذا الشكل:

1. Header

   * اسم المستخدم عند تسجيل الدخول.
   * زر الإشعارات.
   * زر البحث.
   * تصميم مناسب للعربي RTL والإنجليزي LTR.

2. Search

   * حقل بحث واضح وسريع.
   * يفتح البحث العام الموجود حاليًا.
   * لا تنشئ API جديدًا.

3. Quick Actions
   أزرار كبيرة وواضحة:

   * 🏬 المولات
   * 📷 مسح QR
   * 🏷️ العروض
   * 📦 طلباتي

4. Featured Malls

   * عرض المولات الموجودة فعليًا من API الحالي.
   * Cards احترافية.
   * صورة + اسم المول + معلومات أساسية متاحة من API.
   * الضغط يفتح صفحة المول الموجودة حاليًا.

5. Offers

   * عرض العروض الموجودة حاليًا من API.
   * لا تنشئ بيانات وهمية.
   * إذا لم توجد عروض، أخفِ القسم بدل عرض بيانات تجريبية.

6. Recommended / Popular Products

   * استخدم البيانات الموجودة حاليًا فقط.
   * لا تضف endpoint جديدًا.
   * إذا لم يوجد مصدر مناسب، لا تنشئ API جديدًا؛ اترك القسم خارج النسخة الحالية.

7. Bottom Navigation
   اجعل التنقل واضحًا:

   * الرئيسية
   * المولات
   * العروض
   * الطلبات
   * الحساب

8. QR Scanner
   يجب أن يبقى الوصول إليه واضحًا من Home، مع استخدام scanner الموجود حاليًا والذي تم اختباره.
   لا تعيد كتابة QR logic.

9. UX

   * Safe areas.
   * RTL/LTR.
   * Light/Dark.
   * حالات loading جيدة.
   * Empty states.
   * Error states.
   * Pull to refresh.
   * منع العناصر من الخروج عن الشاشة.
   * تصميم مناسب للشاشات الصغيرة والكبيرة.
   * لا تستخدم animations مبالغ فيها.
   * الأولوية للأداء وسرعة التحميل.

10. التصميم
    أريد شكلًا احترافيًا قريبًا من تطبيقات التجارة الحديثة:

* بطاقات نظيفة.
* مساحات مناسبة.
* Typography واضحة.
* أزرار سهلة اللمس.
* hierarchy واضح.
* لا تزدحم الصفحة بالمعلومات.

قبل تعديل الكود:

* افحص Home الحالية والـ components الموجودة.
* أعد استخدام الـ components والـ API hooks الموجودة عندما يكون ذلك مناسبًا.
* لا تكرر منطق جلب البيانات.
* لا تكسر أي route موجود.

بعد التنفيذ:

* TypeScript
* Lint
* Expo Doctor
* Android production bundle
* iOS production bundle
* git diff --check

وأريد في النهاية تقريرًا مختصرًا:

1. الملفات التي تغيرت.
2. ما الذي تغير في Home.
3. APIs الموجودة التي تم إعادة استخدامها.
4. تأكيد أن Checkout / Orders / QR Scanner لم تتأثر.
5. نتائج الاختبارات.

لا تنفذ أي تغيير خارج `artifacts/smartmall-mobile`.
